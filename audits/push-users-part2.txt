VERIFY 3 — BEHAVIOUR
─────────────────────────────────────────────────────────────────

Search debounce (one request after typing):
  searchInput → debounce useEffect → 300ms → setSearch → triggers fetch.
  Only one apiGet call fires; the 300ms delay means rapid keystrokes
  don't send a request per keystroke.

Stale-response guard:
  Each fetch useEffect sets `cancelled = false` at start and returns
  `() => { cancelled = true; }`. If a new effect runs before the previous
  resolves, the previous `.then` checks `if (!cancelled)` and skips
  state updates. Identical pattern to existing ChannelDrawer.

Filter chips switch views:
  setViewMode → resets page to 0 (via useEffect dep) → new fetch.
  viewMode === 'revisited' uses /revisited endpoint; 'all' uses /users.

Export hits users.csv with active filters:
  handleExport builds URLSearchParams from {from,to,search,typeFilter,
  originFilter} — same params as the users fetch — then fetches
  /users.csv with the same Authorization header.

Email/WhatsApp drawers and Pending tab: UNCHANGED.
  Source check (checkDrawerIntegrity): 12/12 PASS.
  The guard `channel === 'push' && activeTab === 'sent'` means:
  - email+sent → DrawerItem (old path)
  - whatsapp+sent → DrawerItem (old path)
  - push+pending → DrawerItem (old path)
  - push+sent → PushUsersPanel (new path)

Reload on dashboard date range change:
  from/to are props from ChannelDrawer → PushUsersPanel.
  useEffect([...from, to]) re-fetches when from/to change.

Cache per userKey+range:
  DetailView uses cacheRef keyed by `count:${rangeKey}` and
  `revisit:${rangeKey}:${page}`. Switching Count/Revisit tabs reuses
  cached data if already fetched for the same user+range.

     timer scheduling from the .then() handler.
  2. "success state" test: moved jest.useFakeTimers() to BEFORE saveBtn.click()
     so the 2000ms setTimeout is captured as a fake timer from the start.
     Uses await Promise.resolve() � 2 (microtask flushes) instead of
     setTimeout(r, 0) to flush the fetch .then() callback � avoids
     fake-timer interaction with real timer in await.
