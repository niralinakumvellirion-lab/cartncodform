── How to get the deployed Function ID ─────────────────────

At sync time, backend/services/tierSync.js queries the Shopify Admin API:

  query { shopifyFunctions(first: 25) { nodes { id apiType title } } }

Filter: apiType === 'product_discounts' AND title === 'Quantity Tier Discount'.
The `id` (GID: gid://shopify/ShopifyFunction/…) is passed to
discountAutomaticAppCreate.
Scope needed: read_discounts (already present ✓). No extra scope required.

── Stacking / combinesWith ─────────────────────────────────

Shopify docs (https://shopify.dev/docs/apps/build/discounts/combine-discounts):
"If the automatic discount and the discount code can't be combined, then the
discount with the higher value is applied to the order."

Birthday code (discountCodeBasicCreate in backend/routes/discounts.js):
  No combinesWith field in the mutation input (lines 131-138). Shopify
  default when combinesWith is omitted on a code discount:
    orderDiscounts:  false
    productDiscounts: false
    shippingDiscounts: false
  → birthday codes cannot stack with other discounts.

Quantity tier automatic discount (discountAutomaticAppCreate in tierSync.js):
  combinesWith: { orderDiscounts: false, productDiscounts: false,
                  shippingDiscounts: false } — all false, explicitly set.

RESULT: A customer who has both an automatic tier discount and uses a
birthday code will get whichever gives the higher value — Shopify decides.
They cannot stack. Birthday code NOT changed.

STEP 2 — CONFIG + PURE HELPER
═══════════════════════════════════════════════════════════

DiscountConfig.quantityTiers schema added:
  enabled: false
  heading: 'Buy more, save more'
  accentColor: '#4F46E5'
  layout: 'cards'    ('cards' | 'list')
  scope: 'all'       ('all' only; 'collections' shown disabled in UI)
  tiers: [
    { minQty: 2, percent: 10, badge: '' },
    { minQty: 3, percent: 15, badge: 'Most popular' },
    { minQty: 4, percent: 25, badge: 'Best value' },
  ]
  discountId: ''     (Shopify automatic discount GID — not exposed via proxy)
  lastSyncAt: null
  lastSyncError: ''

Validation rules (PATCH discounts.js):
  - tiers: 1–4 items (400 if outside)
  - minQty: integer 2–99, strictly ascending across tiers (400 if violated)
  - percent: integer 1–80, strictly ascending across tiers (400 if violated)
  - badge: ≤ 20 chars
  - heading: ≤ 60 chars (trimmed)
  - accentColor: must match /^#[0-9A-Fa-f]{6}$/ — else default '#4F46E5'
  - unknown keys ignored
  - NO silent clamping — any violation returns 400 with a clear message

GET /discount-config (proxy) exposes:
  quantityTiers: { enabled, heading, accentColor, layout, tiers }
  NOT discountId, lastSyncAt, lastSyncError.

backend/utils/quantityTiers.js (pure, no dependencies):
  sanitizeTiers(raw)          — validates + normalises, throws on error
  pickTier(tiers, qty)        — highest tier whose minQty <= qty, or null
  discountedUnitPrice(p, pct) — round half-up 2 decimals

STEP 3 — SHOPIFY FUNCTION
═══════════════════════════════════════════════════════════

Extension directory: extensions/quantity-tier-discount/
  shopify.extension.toml
  src/run.js         — function logic (CJS; esbuild bundles to dist/index.js)
  src/run.graphql    — input query
  package.json

Function target: purchase.product-discount.run (api_version 2025-01)

Logic:
  1. Parse config from discountNode.metafield(namespace:"cartncodform",
     key:"function-configuration").value — invalid JSON → no discount.
  2. If !config.enabled or no tiers → empty discounts.
  3. Group cart lines by product GID (sum quantities across variants).
  4. For each product: pickTier(config.tiers, totalQty) → highest qualifying tier.
  5. If tier found: one discount entry per product, targets = all variant lines,
     percentage = tier.percent, message = "Buy N+, save X%".
  6. Return { discountApplicationStrategy: 'MAXIMUM', discounts }.

STEP 4 — SYNC SERVICE
═══════════════════════════════════════════════════════════

backend/services/tierSync.js:
  syncTiers(shopDomain) → { synced: bool, discountId?, error? }
  - Attempts shop metafield write (warns on failure — needs write_metafields).
  - On enabled=false: deactivates / deletes existing automatic discount.
  - On enabled=true: getFunctionId → discountAutomaticAppCreate (create) or
    discountAutomaticAppUpdate (update); sets discount node metafield.
  - Stores discountId, lastSyncAt, lastSyncError on DiscountConfig.
  - Sync failure does NOT fail the config save.

combinesWith: { orderDiscounts: false, productDiscounts: false,
                shippingDiscounts: false }

backend/scripts/syncQuantityTiers.js:
  Dry-run by default; --apply to execute.
