=== "Coming up" sidebar ===

Location: DashboardScreen.jsx lines 1616–1719

Data source: availableFestivalCalendar, a state var derived from:
  1. festivalCalendar — fetched from GET /api/push/festivals or falls back to
     FESTIVAL_CALENDAR_FALLBACK (hardcoded in DashboardScreen.jsx lines 321–505)
  2. queuedFestivalNames — names of festivals already queued (excluded from sidebar)

getUpcomingFestivals(list, 10): filters to diffDays 0-60, sorts by nearest,
slices to 10.

upcomingFestivals.slice(0, 5) shown in sidebar.

Each item in the sidebar: name, date, emoji, imageUrl (from festivals.json via
the /api/push/festivals endpoint). The thumbnail is a 44×44px img (objectFit:
cover) or the emoji fallback.

"days away" label: formatRelativeDate(diffDays):
  0 → 'Today'
  1 → 'Tomorrow'
  2-13 → 'In N days'
  14+ → 'In N week(s)'

diffDays: computed as Math.ceil((festivalLocalMidnight - localToday) / msPerDay)

The reminder chip will be added to the existing sidebar item IF one exists for
the same festival (matched by name from reminder.festival.name). If no sidebar
item exists for that festival, do NOT add one.

=== backend/data/festivals.json structure ===

Fields per entry:
  name      string  — "Navratri", "Dussehra", etc.
  date      string  — "YYYY-MM-DD" (ISO date, lexicographically sortable)
  emoji     string  — single emoji character
  suggestion string
  message   string  — default push message body
  searchTerm string
  imageUrl  string  — Cloudinary URL for the festival photo

=== nextFestivalName() in emailTemplates.js ===

Location: backend/routes/emailTemplates.js line 68

function nextFestivalName() {
  const today = new Date().toISOString().slice(0, 10);
  const next = FESTIVALS.find(f => f.date >= today);
  return next ? next.name : 'festive season';
}

Uses UTC "today" (new Date().toISOString().slice(0, 10)), not store timezone.
Will be refactored to use upcomingFestival() from the new festivals.js utility.
