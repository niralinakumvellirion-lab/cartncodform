1. WHAT CHANGED IN WaRow
============================================================
File: frontend/app/admin/screens/Settings.jsx
Function: WaRow (~line 1106)

NEW PROPS added (all optional, with sensible defaults):
  fieldPad        — padding string for the tel input; vertical component
                    extracted and applied to the select (default: '8px 12px')
  fieldFontSize   — number; font-size for both select and tel (default: compact?11:12)
  fieldBorderWidth — number; border-width in px (default: 1)
  fieldHeight     — number; explicit element height, for styles that size
                    email inputs by height rather than padding (default: none)

How heights are matched:
  tel input:  uses `pad` (=fieldPad) and optional `height:fieldHeight`
  select:     uses selPad = `${vp} 20px ${vp} 8px` where vp = pad.split(' ')[0],
              and optional `height:fieldHeight`.
              Same vertical padding as tel → same intrinsic height without
              fieldHeight; same explicit height when fieldHeight is set.
              Right padding is 20px to make room for the chevron indicator.

Chevron indicator:
  Old: appearance:none with no visual arrow (native arrow hidden, nothing added).
  New: appearance:none + absolutely-positioned inline SVG chevron (path "M1 1l4 4
       4-4", stroke=currentColor, 10×6px) inside a relative wrapper div.
       The wrapper carries flexShrink:0 and the fixed width (compact?68:82).
       The select fills 100% of the wrapper. The chevron is centred vertically
       with top:50%, transform:translateY(-50%), pointerEvents:none, opacity:0.55.

border string: `${bw}px solid ${inputBorder || '#e5e7eb'}` — bw from fieldBorderWidth.
