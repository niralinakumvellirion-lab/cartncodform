6. RISKS
============================================================

- _ofCard may be null if isCaptureOnly became false between click and fetch resolve
  (impossible at runtime since isCaptureOnly is a closure variable set at render
  time). Guard `isCaptureOnly && _ofCard` is safe in all real paths.
- If _ofCard.parentNode is null (card removed by another path before fetch resolves):
  insertBefore is skipped silently, successCard is orphaned (never shown). cleanup()
  then removes the popup normally. No crash; no visible card. Acceptable edge case.
