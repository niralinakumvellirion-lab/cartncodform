SUMMARY (read-only synthesis, no code changed)
====================================================================
Tracing the full path end to end: AbandonedCustomer DOES carry a real
product image (cartItems[].imageUrl, and a resolved top-level
productImageUrl set via webhooks.js's Admin-API image lookup) -- but
none of that ever reaches a Signal (computeCartAbandon() only pulls
title/productId from the cart item, never its image), so it never
reaches ScheduledJob.payload (brain.js writes payload.imageUrl as a
literal '' with no product-image source available to it), so it never
reaches generateCopy() (which has no image field in its contract at
all) or the final sendPushToCustomers() call (payload.imageUrl || null
is always null for these jobs). The result: every brain-scheduled
cart_abandon/checkout_abandon push notification renders with the same
hardcoded generic shopping-cart icon
(https://img.icons8.com/color/96/shopping-cart--v1.png) for its
icon/badge, and no image at all (image field omitted) -- never the
actual abandoned product's photo, even though that photo is sitting in
the database the whole time, one collection away
(AbandonedCustomer.productImageUrl). Not fixed here -- audit only, per
task scope.
