=== PROBLEM ===

dragEndedRef was declared only in QueueScreen (~line 1710) but also used
in DayDetailsPanel's card onDragStart/onDragEnd (lines 722-729). DayDetailsPanel
is a separate function component — it does not receive dragEndedRef as a prop
and cannot close over QueueScreen's local variables. This would throw a
ReferenceError at runtime on every drag start or drag end in DayDetailsPanel.

=== FIX ===

Added `const dragEndedRef = useRef(false);` as the first line of DayDetailsPanel's
function body (line 608), before all other derived values. This gives DayDetailsPanel
its own independent ref — correct behaviour because DayDetailsPanel manages its own
drag-start/drag-end lifecycle and does not share state with the planning list's
drag cycle.

BEFORE (DayDetailsPanel body, line 607):
  }) {
    const festival = festivalCalendar.find(f => f.date.startsWith(dateStr));

AFTER:
  }) {
    const dragEndedRef = useRef(false);
    const festival = festivalCalendar.find(f => f.date.startsWith(dateStr));

No other changes to the handlers — the existing rAF + flag logic in
DayDetailsPanel (lines 721–729) is correct and unchanged.
