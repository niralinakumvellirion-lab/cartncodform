  + require('../models/StorefrontEvent')
  + require('../models/ProductImageCache')
  + require('../utils/productImage').normalizeImageUrl

  New helpers (all pure / no side effects outside of DB reads):
    extractHandle(path)          — /products/{handle} → 'handle', null otherwise
    isProxiedUrl(url)            — detects *.myshopify.com/cdn/ URLs (skip in imageUrl)
    resolveRecentProducts(shop, profile) → up to 3 products, most recent first:
      - Queries StorefrontEvent by sessionIds + cartTokens, last 30 days
      - Dedupes by productId, keeps best title + handle per product
      - Filters proxied imageUrls; overlays ProductImageCache if available
      - Returns [] when no sessions on profile (home-only visitors)
    applyProductPlaceholder(text, productTitle)
      - Replaces {product} with productTitle
      - Removes {product} cleanly (no extra spaces) when productTitle is null

  GET /:shopDomain/profile/:profileId:
    + Calls resolveRecentProducts(shop, profile)
    + Adds recentProducts to response JSON

  POST /:shopDomain/send:
    + Reads req.body.productHandle (string | absent)
    + Calls resolveRecentProducts(shop, profile)
    + Validates rawHandle against recentProducts → 400 if not found
    + Auto-picks recentProducts[0] when no handle supplied
    + Builds ctaUrl: /products/{handle}?ccf_src=whatsapp&ccf_job={id}
      or home URL when no product
    + Applies applyProductPlaceholder(message, productTitle)
    + Stores productHandle on ScheduledJob.create
    + Renamed storeLink → ctaUrl throughout POST /send

RISKS
======
1. ProductThumb in product selector chip (16px): if no imageUrl is
   available for a product, the placeholder div (16x16 grey square)
   renders. The chip layout uses flex so the size is fixed — no layout
   shift. ✓

2. recentProducts populated at load time: if the customer views a new
   product AFTER the CustomerDetail page loaded, the selector won't
   reflect it until the page is refreshed. This is acceptable for the
   current version.

3. Auto-picked product (recentProducts[0]) may surprise some sellers
   if the most recently viewed product is unrelated to the current
   cart. The seller can override by clicking a different chip or
   "Store home". ✓

4. {product} placeholder: only removed from the message text — not
   from the message template definitions in WA_TEMPLATE_BODY (which
   don't currently use it). The applyProductPlaceholder post-process
   step is a no-op on templates without the placeholder. ✓
