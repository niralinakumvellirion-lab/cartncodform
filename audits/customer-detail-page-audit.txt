DashboardScreen.jsx (appends ?shop=<encoded shop>, '&' if the path already
has a query). Both the desktop and mobile row onClick call
navigate(`/admin/customers/${encodeURIComponent(p._id)}`).
The route wrapper reads shop from useSearchParams and id from useParams.

RESPONSIVE
CustomerDetail tracks window.innerWidth < 900 (resize listener). At 900px
and above: grid minmax(0,3fr) minmax(0,2fr) with Recent activity on the left
and Most interested in + Send notification stacked on the right. Below 900px
it is a single column. Page max width is 1100 (DS.page default 960 is
overridden for the detail page).
