FIX 4 — Enhanced button styling
-------------------------------
Store.js:
  - popup.ctaStyle and mobilePopup.ctaStyle enums expanded from
    ['rounded','square','pill'] to
    ['rounded','square','pill','outlined','soft'].
    Defaults unchanged (popup 'rounded', mobilePopup 'pill').
Settings.jsx:
  - Module-level helper added after LANGS:
      function getCtaStyle(ctaStyle, accent) -> { borderRadius, background,
        color, border } for pill / square / outlined / soft / (default)
        rounded. 'outlined' = transparent bg + 2px accent border + accent
        text; 'soft' = accent+'22' bg + accent text, no border.
  - Button style option list expanded to 5:
      Rounded / Square / Pill / Outlined / Soft
  - Container `<div style={{ display:'flex', gap:'8px' }}>` -> added
    flexWrap:'wrap' (+ row alignItems:'flex-start', label marginTop:'6px')
    so five chips wrap cleanly.
  - Desktop preview IIFE: `const ctaCss = getCtaStyle(ctaStyle, accent);`
    spread into the split Allow button and the card Allow button in place
    of the old hardcoded {background:accent,color:'#fff',border:'none',
    borderRadius:ctaRadius}. Banner Allow button keeps its inverted
    white-on-accent look but takes its corner from ctaCss.borderRadius.
  - Phone-frame preview: `const ctaCss = getCtaStyle(mp.ctaStyle || 'pill',
    accent);` spread into the Allow button (replaces old ctaR ternary).
  - Removed now-unused `ctaRadius` / `ctaR` locals (grep confirms zero
    remaining references).
