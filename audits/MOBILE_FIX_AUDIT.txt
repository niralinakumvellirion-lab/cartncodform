1. lib/api.js — 401 retry with a fresh token
-------------------------------------------
  Both apiGet and apiSend: the old "retry once on 401" block (which called the
  non-existent `getAuthToken(true)` and retried immediately) is replaced with:
    if (res.status === 401) {
      await new Promise((r) => setTimeout(r, 500));   // let App Bridge mint one
      const freshToken = await getAuthToken();
      // fetch again with Bearer freshToken (+ Content-Type)
      if (!retryRes.ok) { const err = await retryRes.json().catch(()=>({}));
        throw new Error(err.error || `${path} failed (${retryRes.status})`); }
      return retryRes.json();   // apiSend: .catch(() => ({}))
    }
  Network errors on the retry still go through describeNetworkError. Only one
  retry; a second 401 now throws the backend's error message.
