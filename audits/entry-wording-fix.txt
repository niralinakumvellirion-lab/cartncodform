ROOT CAUSES (clipped preview + button label bug)
-----------------------------------------------------------------------

ROOT CAUSE 1 — Preview clipping
  The standalone "Entry popup wording" card used a single-column layout.
  The preview div had `maxWidth: 300` with `margin: '0 auto'`, so it
  never filled the available width. Inside the Shopify admin iframe
  (typically 600-700px content width), this made the preview feel narrow
  and disconnected from the fields.

  Fix: Two-column flex layout: fields column (flex:1, minWidth:220) +
  preview column (width:290, flexShrink:0). The preview div now has
  `width:'100%', boxSizing:'border-box', overflow:'hidden'` — it fills
  its 290px column completely with no horizontal overflow.

ROOT CAUSE 2 — Button label appears as empty dark/purple bar
  The `captureButton` preview was rendered as a plain `<div>` with
  `color: '#9ca3af'` (gray). This gray text on a white background looked
  like a barely-visible label, and when the popup background was dark
  or the accent colour was similar to gray, the label disappeared
  entirely, making the element look like an empty dark bar.

  Fix: The captureButton preview is now rendered as an accent-tinted
  button:
    background: accent + '22'     (10% opacity accent fill)
    border: '1px solid ' + accent + '55'  (33% opacity accent border)
    color: accent                  (full accent text — always readable)
    borderRadius: 8, padding: '7px 12px', fontWeight: 600
  The label is now always visible against its own background.

ROOT CAUSE 3 — Gradient bar marginInline broke on older Safari/WebKit
  The old gradient bar used `marginInline: -18` which is a CSS logical
  property not supported in older WebKit. Fixed to `marginLeft: -16,
  marginRight: -16, marginTop: -14` (explicit physical properties,
  matched to the new 14px/16px padding).
