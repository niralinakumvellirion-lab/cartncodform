3. proxy.js — storefront config (NOTES: not in the named list)
------------------------------------------------------------
  The App-Proxy route GET /apps/cartncodform/popup-config only returned
  `popup`. STEP 4 requires the storefront to receive `{ popup, mobilePopup }`,
  so this 2-line change was made:
    `.select('popup mobilePopup')` and
    res.json({ popup: ..., mobilePopup: (store && store.mobilePopup) || {} })
  Without it the liquid's mobilePopupConfig would always be {} and the whole
  feature is inert. node --check -> OK.


4. Settings.jsx — device tabs / activePopup / phone frame / responsive grid
------------------------------------------------------------------------
  * State: added `mobilePopup`/`setMobilePopup` and
    `popupDevice`/`setPopupDevice` ('desktop' default).
  * Fetch: `setMobilePopup(pop.value?.mobilePopup || {})` alongside setPopup.
  * saveSettings: PATCH body is now `{ ...popup, mobilePopup }`.
  * Helper (component scope, before `previews`):
      const activePopup    = popupDevice === 'desktop' ? popup : mobilePopup;
      const setActivePopup = popupDevice === 'desktop' ? setPopup : setMobilePopup;
  * Device tab switcher: a segmented `🖥 Desktop / 📱 Mobile` control inserted
    right after the customizer's back-button header; below it, an indigo note
    "Mobile layout: image stacks above content automatically." shows only when
    popupDevice === 'mobile'.
  * Shared field JSX: the entire customizer field block is wrapped in
      {(() => { const popup = activePopup; const setPopup = setActivePopup;
                return (<> ...all existing fields unchanged... </>); })()}
    i.e. `popup` / `setPopup` are shadowed to the active-device config, so every
    field edits desktop or mobile state with zero per-field rewrites.
  * Layout field: options are `[card, banner]` when popupDevice === 'mobile',
    `[split, card, banner]` otherwise.
  * Preview card (right column): title switches "Desktop preview" /
    "Mobile preview"; the existing split/card/banner preview IIFE now renders
    only for `popupDevice === 'desktop'` (still reads `popup`); a new
    `popupDevice === 'mobile'` branch renders a 200x360 phone frame (notch +
    simulated store skeleton) with a bottom-anchored card-layout popup preview
    driven by `mobilePopup` (bg/text/accent/ctaStyle→radius/image+objectPosition/
    headline/allow/deny).
  * Responsive admin grid: main grid gained `className="ccf-settings-grid"` and
    `gridTemplateColumns: 'minmax(0, 1fr) 380px'`; a module-level guarded
    `<style id="ccf-settings-style">` injection adds
    `@media (max-width:768px){ .ccf-settings-grid{grid-template-columns:1fr!important}
     .ccf-settings-grid>div:last-child{order:-1} }`.
