=== WHAT WAS REMOVED FROM QueueScreen.jsx ===

The raw iframe block that was added in the previous commit:
  {tplPreviewLoading ? (
    <div style={{ fontSize: 12, color: '#9ca3af', padding: '20px 0', textAlign: 'center' }}>
      Loading preview…
    </div>
  ) : tplPreviewHtml ? (
    <div style={{ borderRadius: 8, overflow: 'hidden', border: '1px solid #e5e7eb' }}>
      <iframe
        srcDoc={tplPreviewHtml}
        sandbox="allow-same-origin"
        style={{ width: tplPreviewDevice === 'desktop' ? '100%' : '375px',
                 maxWidth: '100%', height: 420, border: 'none', display: 'block' }}
        title="Email preview"
      />
    </div>
  ) : null}

Problems with the removed code:
  - No scaling: desktop email (logically 640px wide) rendered at panel width with no scale
    transform — would overflow or wrap on narrow panels.
  - Mobile: width capped at 375px but no height calculation — 420px fixed regardless of content.
  - No ResizeObserver: container width changes (panel resize) not tracked.
  - No _injectMeta: missing <base target="_blank"> injection.
  - Separate loading state div instead of EmailPreviewFrame's built-in placeholder.

=== WHAT REPLACED IT ===

Desktop:
  <EmailPreviewFrame
    html={tplPreviewHtml}
    device="desktop"
    loading={tplPreviewLoading}
    templateMode={true}
    subject={subject}
  />
  Component's own wrapper (flex: '1 1 0', minWidth: 0) fills the panel column.
  ResizeObserver reads containerWidth; iframe rendered at 640px logical width then
  scaled via transform:scale(containerWidth/640) — no horizontal scroll, no cropping.
  Max height 560px with scroll for tall emails (same as CustomerDetail).

Mobile:
  <div style={{ height: 480, borderRadius: 8, overflow: 'hidden', border: '1px solid #e5e7eb' }}>
    <EmailPreviewFrame
      html={tplPreviewHtml}
      device="mobile"
      loading={tplPreviewLoading}
      templateMode={true}
    />
  </div>
  The 480px wrapper div gives EmailPreviewFrame's height:100% a resolved value,
  matching PhoneFrame's default inner height in CustomerDetail.
  375px logical width scales to container width; no black band.

Both modes: EmailPreviewFrame's built-in loading/empty placeholders handle all states.

The Desktop/Mobile toggle (tplPreviewDevice state + segmented-control buttons) and
the loadTplPreview function (calling GET /api/email-templates/:id/preview) are unchanged.
