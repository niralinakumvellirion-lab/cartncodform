8. RISKS
============================================================

- Conic-gradient on older browsers (Chrome < 69, Firefox < 83): orbit will be invisible
  (element shows but no gradient). Card still renders (border ring shows as TRACK colour
  without animation). Acceptable degradation.
- `transform-origin` on the orbit <span>: if a theme's CSS globally resets
  `transform-origin` via a wildcard selector, the orbit may spin off-center. The
  element's explicit 420×420 dimensions and overflow:hidden clip make this invisible to
  the user regardless.
- card inserted via `allow.parentNode.insertBefore(_card, allow.nextSibling)`: if
  allow.parentNode is null (allow removed before click fires), insertBefore is silently
  skipped. No crash; no card shown. Edge case not observed in any tested path.
- The `display:''` restore for allow may not match the original computed display if the
  element had an explicit `display` value in its inline style (other than 'none'). All
  call sites for buildAllowBtn use ccfAllowButtonStyle which does NOT set display in
  inline style for the non-compact case. Safe.
