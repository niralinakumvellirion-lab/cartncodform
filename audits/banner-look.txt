[4] document.body safety — code path when script runs in <head>

  The script is an IIFE. At the bottom (lines 4706-4714):

    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', start);
    } else {
      start();
    }
    window.addEventListener('load', function() { if (!ccfStarted) start(); });

  When loaded via <head> (readyState is 'loading'), start() is deferred to
  DOMContentLoaded. When loaded lazily (readyState is 'interactive' or 'complete'),
  start() runs immediately — document.body is guaranteed to exist in both cases.

  start() (line 4649) calls ccfInitBirthdayBanner() (line 4662), which calls
  ccfBannerCreate(), which calls document.body.insertBefore(barWrap, document.body.firstChild).
  document.body is always non-null by the time ccfBannerCreate is reached:
  - Via DOMContentLoaded: body exists by definition.
  - Via readyState !== 'loading': body exists by definition.
  - Via background fetch callback (ccfBannerApplyConfig): executes after Promise resolves,
    which is always after DOMContentLoaded.

  No document.body null risk.
