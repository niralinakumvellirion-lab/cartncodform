=== PRESETS CHIPS NOTES ===

The spec says chips set ONLY design fields, not words. Implemented as:
  setDraftField('layout', p.layout);
  setDraftField('color',  p.color);
  setDraftField('hFont',  p.hFont);
  setDraftField('bFont',  p.bFont);
  setDraftField('radius', p.radius);
  setDraftField('pageBg', null);
  setDraftField('cardBg', null);
All seven calls use React 18 functional updater (d => ({...d, [k]: v})) so they
batch correctly in a single flush. Words and photo are untouched.
