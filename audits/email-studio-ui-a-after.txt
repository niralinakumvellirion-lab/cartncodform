=== DEVIATIONS FROM SPEC ===

1. Photo upload flow: PhotoCard shows the local thumbnail via FileReader and calls
   onUpload(dataUrl, file) in parent; actual POST /photo call is in EmailTemplates.jsx
   (handlePhotoUpload). This matches the spec's intent; just noted for clarity.

2. The discard confirm for "switch template while dirty" shows at the top of the page
   above the grid (not inline in TemplatePicker). This is cleaner than blocking the
   select change event and avoids needing to pass pendingNav down.

3. The "Actual size" mode sets stage to position:static but the Right column is inside
   a CSS grid. On a real Shopify install (inside the admin iframe) this works correctly;
   in the dev server the admin chrome is absent so the iframe is shorter. Not a bug.

4. NOT IN THIS PHASE (E3b): layout picker, colour/background palettes, font pickers,
   presets, Surprise me — all absent as specified.
