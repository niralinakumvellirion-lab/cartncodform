--- DEVIATIONS ---

1. Initial deviceView: spec says initialise from band width in useLayoutEffect.
   Implemented with a post-measure setState in useLayoutEffect; the initial
   useState default is 'both'. This means on very first render (SSR) the server
   sees 'both', then client corrects. Functionally identical for an iframe-hosted
   app; no hydration mismatch because the workspace is client-only.

2. Looks presets collapse breakpoint: spec says 900px. Implemented via `bandWide`
   boolean (el.clientWidth >= 900) measured in the same useLayoutEffect as wsH.

3. Broadcast count cap: spec is silent on a cap; implemented the existing
   "free plan ≤90" warning from the previous version (kept from pre-audit state).
