2. WHAT WAS CHANGED
============================================================

A. ccfBuildWhatsappFields (ccf-push.js lines 163–246 after edit)

  New opts fields accepted (all optional, backward-compatible):
    height      (number)  — explicit px height; applied to both select and tel
    fontSize    (string)  — e.g. '15px'; appended after baseStyle, overrides '13px'
    borderRadius (string) — e.g. '999px'; appended after baseStyle, overrides '12px'
    telPadding  (string)  — e.g. '0 16px'; appended after baseStyle's 11px 14px

  inputBg default: '#ffffff' → '#f9fafb'  (matches ccfInputStyle background)

  Select: padding changed from '0 6px' to selPad = '${selVertPad} 20px ${selVertPad} 8px'
    where selVertPad = first component of telPadding (or '11px' default).
    Right-padding 20px accommodates the chevron; left-padding 8px gives text room.
    'padding:0 6px' previously made the select text sit at the browser's default
    vertical position (near top); now it matches the email's vertical padding exactly.

  Select chevron: appearance:none with background-image SVG chevron
    (path M1 1l4 4 4-4, stroke=inputFg, stroke-opacity=0.55, 10×6px)
    built via encodeURIComponent — no DOM wrapper needed, no innerHTML.
    background-position:right 6px center.

  backgroundColor / backgroundImage / backgroundRepeat / backgroundPosition
    replace the old `background:inputBg` shorthand so the chevron is additive.

  Tel: telPad/fFontSize/fRadius/fHeight appended after baseStyle (override as needed).
