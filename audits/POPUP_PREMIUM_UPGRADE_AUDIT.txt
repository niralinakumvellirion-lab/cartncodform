DEVIATION FROM THE LITERAL SNIPPET (verified, not guessed)
--------------------------------------------------------------
STEP 2.3's given code was:
  offerBox.innerHTML = '...' + offerText + ' — ' + ccfPct() + '% off';
Neither `offerText` nor a no-arg `ccfPct()` exist in this file:
  - `ccfPct(key)` requires a key ('emailDiscount' etc.) — called with no
    args it evaluates `discountConfig[undefined]`, which is always
    undefined, so `ccfPct()` always returns 0. Using it here would have
    printed "... — 0% off" on every badge, unconditionally.
  - There is no `offerText` variable anywhere in the card branch (or
    elsewhere) to reference.
  Used the existing, already-correct, already-percentage-aware
  ccfDiscountOfferText() helper instead (added in the prior redesign
  pass) — it already returns text like "Add your email to get 15% off"
  per whichever discount action is actually configured, with the real
  percentage embedded once, correctly.
STEP 2.2's given snippet also had a stray `'id:ccf-allow-btn',` INSIDE the
CSS declaration array (not valid CSS — would sit as dead text in the style
attribute). Dropped; buildAllowBtn() already sets the id the normal way.
