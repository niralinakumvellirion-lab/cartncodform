=== DRAFT STATE IN EmailTemplates.jsx ===

Held as:
  const [draft, setDraft]           = useState(EMPTY_DRAFT);
  const [savedDraft, setSavedDraft] = useState(null);
  const dirty = useMemo(
    () => !!savedDraft && JSON.stringify(draft) !== JSON.stringify(savedDraft),
    [draft, savedDraft]
  );

Updater function:
  function setDraftField(field, value) {
    setDraft(d => ({ ...d, [field]: value }));
    setSaveOk(false);
    setSaveError(null);
  }

Every card calls setDraftField(fieldName, newValue). The dirty flag is a
pure string-compare — no per-field tracking needed.

=== DESIGN FIELDS IN DRAFT (null = "automatic") ===

Field       Default in EMPTY_DRAFT   Null means
----------  -----------------------  ----------------------------------------
layout      null                     DEFAULT_LAYOUT_BY_TYPE[draft.type]
                                       special_offer→'poster', festival→'float',
                                       normal→'letter'
color       null                     store.primaryColor || '#4f46e5'
hFont       null                     'arial'
bFont       null                     'arial'
radius      null                     'round'
pageBg      null                     bgDefaults(layout, color).page (engine)
cardBg      null                     bgDefaults(layout, color).card (engine)
showLogo    false                    (boolean, not nullable)

designFromTemplate() in emailEngine.js resolves all nulls at render time
before calling renderEmail(). New cards MUST call setDraftField with null
to mean "auto" — never with a computed value that would defeat the auto logic.

=== STORE BRAND DATA FLOW ===

Source: GET /api/profiles/:shopDomain/settings

In EmailTemplates.jsx:
  const [store, setStore] = useState({ shopName:'', logoUrl:null, primaryColor:null, shopDomain:'' });

  useEffect(() => {
    const shop = shopParam || window.shopify?.config?.shop || '';
    if (!shop) return;
    setStore(s => ({ ...s, shopDomain: shop }));
    apiGet(`/api/profiles/${encodeURIComponent(shop)}/settings`)
      .then(data => {
        setStore({
          shopName:     data.shopName     || '',
          logoUrl:      data.logoUrl      || null,
          primaryColor: data.primaryColor || null,
          shopDomain:   shop,
        });
      })
      .catch(() => {});
  }, [shopParam]);

  store.primaryColor is the fallback brand colour when draft.color is null.
  store.logoUrl is passed to designFromTemplate → used when showLogo=true.
  store is passed as the second arg to designFromTemplate(draft, store, opts)
  and also passed as a prop to PreviewStage.

In Phase E3b, store.primaryColor will also seed the COLORS swatches row
and the brandShades helper to generate tinted background options.
