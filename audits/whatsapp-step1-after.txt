4. backend/routes/whatsapp.js — new file

  4 routes, all requireAuth + requireStoreOwner with :shopDomain path param:

  POST /:shopDomain/send
    - Validates profileId, checks consentedAt present and optedOutAt absent
    - Creates ScheduledJob(channel='whatsapp', status='sent') — never 'pending'
    - Returns { url, jobId } where url is wa.me link with ccf_src/ccf_job attribution

  GET /:shopDomain/stats?from=&to=
    - pending = opted-in profiles with no whatsapp job (distinct profileIds)
    - sent = whatsapp ScheduledJobs with sentAt in range
    - clicked/carted/purchased via AttributedEvent distinct job counts

  POST /:shopDomain/opt-out
    - Sets channels.whatsapp.optedOutAt on profile

  GET /:shopDomain/profile/:profileId
    - Returns { whatsapp channel data, whatsapp messages only }

  No PII logged. Business logic fully in backend.
