DEVIATION FROM THE LITERAL TASK SNIPPET (verified, not guessed)
=========================================================================
The task's given apiSend() timeout snippet assumed a single `fetch(url,
options)` call with one `return res;` — but the ACTUAL apiSend()
function (re-read in full before editing) makes TWO separate fetch()
calls: the initial request, and a one-time retry after a 401 (App
Bridge session tokens live ~1 minute; the retry waits 500ms then uses
a freshly-minted token). Applying the given snippet verbatim to only
the first fetch would have left the 401-retry fetch with no timeout at
all — exactly the same "Saving..." forever failure mode the task is
trying to fix, just moved to a less-common path.

Extracted a small shared helper, `fetchWithTimeout(url, options,
method)`, applying the AbortController + 30s timer + AbortError
handling to BOTH fetch call sites (the initial attempt and the 401
retry) instead of duplicating the try/catch/finally block twice
inline. Same behavior as the given snippet at each individual fetch
site (30s abort, "Request timed out" on AbortError, existing
describeNetworkError() message otherwise) — just factored once instead
of copy-pasted, since apiSend() needs it in two places.

apiGet() was NOT touched — the task named apiSend() specifically, and
"DO NOT touch any other files" plus "Find apiSend() function" together
scope this to apiSend() only. apiGet() still has no timeout; flagging
this as an intentional scope boundary, not an oversight, in case a
future task wants the same fix applied there.


EXACT CODE — frontend/lib/api.js (new helper + apiSend(), full)
=========================================================================
// 30s client-side cutoff so a hung backend request doesn't leave the UI
// showing "Saving..." indefinitely — fetch() has no built-in timeout.
const REQUEST_TIMEOUT_MS = 30000;

async function fetchWithTimeout(url, options, method) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), REQUEST_TIMEOUT_MS);
  try {
    return await fetch(url, { ...options, signal: controller.signal });
  } catch (err) {
    if (err.name === 'AbortError') throw new Error('Request timed out');
    throw new Error(describeNetworkError(err, method, url));
  } finally {
    clearTimeout(timer);
  }
}

export async function apiSend(path, method, body) {
  const url = `${BACKEND_URL}${path}`;
  const token = await getAuthToken();
  const headers = {
    'Content-Type': 'application/json',
    ...(token ? { Authorization: `Bearer ${token}` } : {}),
  };

  const res = await fetchWithTimeout(url, {
    method,
    headers,
    body: JSON.stringify(body),
  }, method);

  if (res.status === 401) {
    await new Promise((r) => setTimeout(r, 500));
    const freshToken = await getAuthToken();
    const retryRes = await fetchWithTimeout(url, {
      method,
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${freshToken}`,
      },
      body: JSON.stringify(body),
    }, method);
    if (!retryRes.ok) {
      const err = await retryRes.json().catch(() => ({}));
      throw new Error(err.error || `${method} ${path} failed (${retryRes.status})`);
    }
    return retryRes.json().catch(() => ({}));
  }

  const data = await res.json().catch(() => ({}));
  if (!res.ok) {
    throw new Error(data.error || `${method} ${path} failed (${res.status})`);
  }
  return data;
}
