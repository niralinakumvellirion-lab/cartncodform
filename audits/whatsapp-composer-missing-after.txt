DIAGNOSIS SUMMARY (see whatsapp-composer-missing-before.txt)
-------------------------------------------------------------
Root cause: rankWaSuggestions() returned [] for canOrder=true /
canFollowup=false customers with no eligible order suggestions. After
0ff1081 the product chips started rendering for these customers (new
recentProducts API data), making the empty suggestion/editor state
newly visible. The JSX structure was correct throughout.

      return [{ key:'say_hello', purpose:'order', title:'Say hello',
                reason:()=>'WhatsApp enabled',

                eligible:()=>true }];
    }

  Ensures editor always shows when WaComposer renders (canWa=true
  guarantees canFollowup OR canOrder, now both get a fallback).
