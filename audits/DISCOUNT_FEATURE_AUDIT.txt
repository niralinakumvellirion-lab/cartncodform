DISCOUNT FEATURE — SELF AUDIT
=============================
Branch: discount-feature
Date: 2026-09-10
Feature: reward storefront visitors who subscribe (push / email / phone /
both) with an auto-generated single-use Shopify discount code, shown
inline in the push prompt.


FILES CREATED (4)
-----------------
1. backend/models/DiscountConfig.js
   - Mongoose model, one row per shop (keyed by shopDomain, like SignalConfig).
   - Four rule sub-docs: pushDiscount, emailDiscount, phoneDiscount, bothDiscount.
     Each: { enabled:Boolean(false), percentage:Number(min0/max100),
             maxUses:Number(100), expiryDays:Number(7), prefix:String }.
   - offerHeadline:String (default 'Get a discount on your first order!').
   - updatedAt:Date.
   - discountConfigSchema.index({ shopDomain: 1 }, { unique: true }).
     (field-level `unique:true` dropped to avoid Mongoose duplicate-index
     warning — matches SignalConfig.js convention; unique index still enforced.)

2. backend/routes/discounts.js
   - Exports the router PLUS generateDiscount() and defaultConfig() helpers
     (proxy.js requires them; no circular dep — discounts.js never requires proxy.js).
   - GET  /api/discounts/:shopDomain/config   (requireAuth + requireStoreOwner)
       -> { config }  (full defaults object when no row exists)
   - PATCH /api/discounts/:shopDomain/config  (requireAuth + requireStoreOwner)
       -> upsert; each rule sub-doc replaced wholesale and clamped
          (percentage 0-100, maxUses 1-100000, expiryDays 1-365,
           prefix uppercased, [A-Z0-9] only, <=10 chars); offerHeadline <=200 chars
       -> { updated: true, config }
   - POST /api/discounts/:shopDomain/generate  (App Proxy signature hard-enforced)
       -> body { action, email?, phone?, sessionId } -> generateDiscount()
   - generateDiscount(shopDomain, body):
       * validates action in [push,email,phone,both]
       * loads DiscountConfig + Store(accessToken)
       * if rule missing/disabled -> { code: null }
       * code = <prefix>_<6 rand base36 upper>
       * Shopify Admin GraphQL discountCodeBasicCreate:
           percentage = cfg.percentage/100, items.all, appliesOncePerCustomer,
           usageLimit = cfg.maxUses, startsAt now, endsAt now+expiryDays
       * userErrors -> { code: null, error }
       * best-effort upsertProfile(email/phone, sessionId) — never blocks, no PII logged
       * -> { code, percentage, expiryDays }

3. frontend/app/admin/screens/Discounts.jsx
   - Props { shop }. State: config, loading, saving, success, error.
   - GET /api/discounts/${shop}/config on mount (reads data.config).
   - "Popup offer text" card (offerHeadline input).
   - 4 toggle cards (Push / Email / Phone / Email+Phone); when enabled shows a
     2-col grid: Discount % slider (5-50), Max uses, Expires after (days),
     Code prefix (monospace, uppercased). Div-based inline styles, no Polaris.
   - saveConfig(): PATCH the whole config object; re-hydrates from res.config.

4. frontend/app/admin/discounts/page.js
   - Suspense + AppProvider + NavMenu + <DiscountsScreen shop=.. />, same
     pattern as customers/page.js. NavMenu includes the new Discounts link.
