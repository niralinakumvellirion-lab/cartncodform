STATE VARIABLES IN RevenueStats
================================================================
  NONE. No useState, no useReducer, no refs.

  Hooks used (verbatim from source):
    useMemo(() => { ...derive stats... }, [customers])
      -> produces `stats` = {
           totalRevenue, pushRevenue, recoveredCount, recoveryRate,
           totalCarts, revenuePerSend, topCurrency, mixedCurrencies,
           hasData
         }
      derivation (all unchanged):
        recovered      = customers.filter(c => c.status === 'recovered')
        withRevenue    = recovered.filter(c => typeof c.recoveredRevenue === 'number' && c.recoveredRevenue > 0)
        totalRevenue   = withRevenue.reduce((s,c) => s + c.recoveredRevenue, 0)
        pushAttributed = withRevenue.filter(c => c.attributionSource === 'push')
        pushRevenue    = pushAttributed.reduce((s,c) => s + c.recoveredRevenue, 0)
        totalCarts     = customers.length
        recoveryRate   = totalCarts > 0 ? ((recovered.length/totalCarts)*100).toFixed(1) : '0.0'
        currencies     = withRevenue.map(c => c.recoveredCurrency).filter(Boolean)
        topCurrency    = most-common currency, or null
        mixedCurrencies = new Set(currencies).size > 1
        revenuePerSend = pushAttributed.length > 0 ? (pushRevenue/pushAttributed.length).toFixed(2) : null
        hasData        = withRevenue.length > 0

  Internal helper (verbatim from source):
    formatCurrency(amount)
      -> stats.mixedCurrencies ? amount.toFixed(2)
         : `${symbol}${amount.toFixed(2)}` where symbol is
           INR '₹' / USD '$' / EUR '€' / '' (fallback)
