3. StageBadge COMPONENT — full code
====================================================================

function StageBadge({ customer }) {
  const orders = customer.orders?.count || 0;
  const hasCart = customer.identifiers?.cartTokens?.length > 0;

  let label, color, bg;
  if (orders > 1) {
    label = 'Repeat buyer'; color = '#16a34a'; bg = '#dcfce7';
  } else if (orders === 1) {
    label = 'Bought once'; color = '#2563eb'; bg = '#dbeafe';
  } else if (hasCart) {
    label = 'Has cart'; color = '#d97706'; bg = '#fef3c7';
  } else {
    label = customer.stage === 'lapsed' ? 'Going quiet' : 'Visitor';
    color = '#6b7280'; bg = '#f3f4f6';
  }

  return (
    <span style={{
      display: 'inline-block',
      padding: '2px 8px',
      borderRadius: 20,
      fontSize: 11,
      fontWeight: 600,
      color,
      background: bg,
      whiteSpace: 'nowrap',
    }}>
      {label}
    </span>
  );
}

(Two bugs in an earlier given version of this component -- reading
customer.orders directly instead of customer.orders?.count, and
checking customer.stage === 'lapsing' instead of 'lapsed' -- were
found and fixed in a prior task; both fixes are already reflected in
the code shown above. See the inline comment immediately above this
function in the file, and audits/customers-ui-redesign-audit.txt, for
the full explanation.)
