SELF-AUDIT: Export panel — Sidekick clearance fix
==================================================
Date: 2026-10-14
File changed: frontend/app/admin/screens/Customers.jsx only

─── WHAT CHANGED ────────────────────────────────────────────────────────────────

1. Added constant (line ~145, before ExportPanel function):

     const SIDEKICK_CLEARANCE = 80;   // px

   Value: 80. Shopify Sidekick bar is ~64px tall; 80px leaves ~16px gap
   between the bar's top edge and the Download button.

2. Sticky footer padding (one line changed):

   Before:
     padding: '14px 20px'

   After:
     padding: `14px 20px ${SIDEKICK_CLEARANCE}px`

   Expands to: padding-top 14px, padding-right/left 20px,
               padding-bottom 80px.

   The border-top, flexShrink:0, and background:#fff are unchanged.
   The scrollable filter area (flex:1, overflowY:'auto') sits above the
   footer in the flex column and is unaffected — it still scrolls
   independently and nothing is hidden behind the footer.

─── LAYOUT VERIFICATION ─────────────────────────────────────────────────────────

Desktop (>768px, panel 560px wide):
  Flex column: header (fixed) → scrollable body (flex:1) → sticky footer.
  Footer is now 14+80=94px tall at minimum (before the button row height).
  The Download button and Reset button are in the footer above the 80px pad,
  so they sit above the Sidekick bar. Reset remains fully clickable.

Mobile (≤768px, isMobile=true → panel width 100%):
  Same flex column structure, same footer padding — no separate mobile
  override was needed. The 80px bottom pad is the same on both breakpoints,
  which is correct because Sidekick appears on mobile too.

─── WHAT COULD NOT BE VERIFIED WITHOUT A BROWSER ────────────────────────────────

- Whether 80px is the exact right amount for every Shopify plan / Sidekick
  state (collapsed vs. expanded, different screen densities). Sidekick may
  not appear on all plans; on those the footer has extra whitespace, which
  is acceptable.
- That the Sidekick bar doesn't shift when the panel is open (some Shopify
  admin layouts reflow the fixed-position elements inside the iframe).
- Visual appearance of the footer on a real device at 768px boundary.
- That flexShrink:0 on the footer actually prevents compression when the
  panel content is very short (short enough that the flex column fits
  without scrolling).

npm run build: clean, 0 errors, 0 type errors.
/admin/customers route compiled successfully.
Backend tests not re-run (frontend-only change, no backend files touched).
