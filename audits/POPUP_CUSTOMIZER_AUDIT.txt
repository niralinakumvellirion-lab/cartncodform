2. GET /popup-config PROXY ROUTE  (backend/routes/proxy.js)
---------------------------------------------------------
  New route: router.get('/popup-config', ...)  (mounted at /apps/cartncodform)
    - verifyProxySignature(req.query) HARD-enforced (403 on failure), same as /cod-form.
    - shop = String(req.query.shop||'').trim().toLowerCase()
    - Store.findOne({ shopDomain: shop }).select('popup')
    - Content-Type: application/json
    - Access-Control-Allow-Origin: *
    - Cache-Control: no-store
    - Body: { popup: (store && store.popup) || {} }
    - catch -> 500 { popup: {} } with the same JSON + CORS headers so the
      storefront still parses a valid body and falls back to defaults.
  node --check routes/proxy.js -> OK


3. GET / PATCH /api/profiles/:shopDomain/popup  (backend/routes/profiles.js)
------------------------------------------------------------------------
  Added a POPUP_FIELDS whitelist (the 12 field names above) and two routes,
  placed before the /weights route.

  GET  /:shopDomain/popup
    - requireAuth + requireStoreOwner
    - Store.findOne({ shopDomain: shop }, 'popup'); 404 if no store
    - Response: { popup: store.popup || {} }

  PATCH /:shopDomain/popup
    - requireAuth + requireStoreOwner
    - Iterates POPUP_FIELDS; for each key present in req.body, sets
      set['popup.' + key] = req.body[key]  (dot-notation partial merge,
      unknown keys ignored — no arbitrary $set injection)
    - 400 { error } when no known field supplied
    - Store.updateOne({ shopDomain: shop }, { $set: set })
    - Response: { updated: true }
  Scoped by shopDomain (from the URL param), never by email. node --check -> OK

  b) fetchPopupConfig() added (just before initIntentTriggers):
       - fetch(window.location.origin + '/apps/cartncodform/popup-config')
       - r.ok ? r.json() : null ; on {popup:{}} object -> popupConfig = data.popup

  c) start() now calls:

  d) showSoftPrompt() now resolves appearance from popupConfig, all with
     `|| default` fallbacks so an empty config renders exactly the old prompt:
       POSITION  -> POS map: bottom-right {bottom:20px;right:20px} (default),
                    bottom-left, center {top:50%;left:50%;transform:translate(-50%,-50%)},
                    top-right, top-left

                    color = textColor||#111827, border-radius = (borderRadius??12)+px,
                    font-family = fontFamily||inherit
       ACCENT    -> #ccf-allow-btn: background = accentColor||#4f46e5
       IMAGE     -> if imageUrl: <img> prepended inside #ccf-push-prompt above the
                    text, style width:100%;border-radius:8px;margin-bottom:8px;
                    object-fit:cover;max-height:120px

       BUTTONS   -> allow.textContent = allowText||'Allow',
                    deny.textContent  = denyText||'No thanks'
       BRANDING  -> if showBranding: <div> "Powered by CartnCodForm", 10px #9ca3af,
