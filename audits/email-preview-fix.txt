=== STEP 1c — Root causes ===

1. DESKTOP — renders at container width (~320-400px), not 640px logical width.
   iframe width:'100%' inherits the flex container's narrow width.
   A 600px email table collapses to its narrow layout or adds a horizontal scrollbar.
   Fix: render iframe at fixed 640px logical width + CSS transform: scale(containerW/640).

2. DESKTOP — height is a hard-coded 420px, never matches actual content.
   Even if scale were correct the wrapper would cut off the bottom or show dead space.
   Fix: measure documentElement.scrollHeight in onLoad, set wrapper height = min(content*scale, 560).

3. MOBILE — black band at bottom.
   containerH = round(700 * 234/360) = 455px, but phone screen = 480px.
   25px of black '#000' from the phone screen shows below the iframe wrapper.
   Fix: iframe height = max(contentHeight, ceil(screenH/scale)); wrapper = height:'100%'.

4. MOBILE — text appears tiny (iframeW=360 scaled to 234px → ~0.65 logical px per physical px).
   This is actually correct email-on-mobile rendering, but the phone screen inner width
   is 236px (252 outer − 2×8 padding), not 234px. The scale should be 236/375 for a 375px
   logical width. Old code used 360px logical, which is too narrow for a desktop-width email.
   Fix: logical width 375px, scale = containerW/375.

5. Out-of-order template requests: no stale-response guard.
   Switching templates quickly can show the previous template's preview.
   Fix: request counter ref; ignore responses where reqId !== current.
