DEVIATION (verified, not guessed) — same class of bug as the prior task
---------------------------------------------------------------------------
The given snippet calls `ccfPct('push')` for the image badge percentage.
ccfPct(key) indexes discountConfig[key] directly, and the real config
keys are 'pushDiscount' / 'emailDiscount' / 'phoneDiscount' /
'bothDiscount' — there is no 'push' key, so discountConfig['push'] is
always undefined and ccfPct('push') always returns 0. Since the badge is
only appended `if (pct)`, this would have silently suppressed the badge
on every popup, always. Fixed to ccfPct('pushDiscount') in both the card
badge and the new split-desktop badge — confirmed via grep that both call
sites use the corrected key.
