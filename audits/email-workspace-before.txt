═══ PreviewStage.jsx — current behaviour ═══

File: frontend/app/admin/screens/emailStudio/PreviewStage.jsx (221 lines).

State: previewWidth ('desktop'|'mobile'), viewMode ('fit'|'actual'), scale.
One iframe, one width (DESKTOP_W=600, MOBILE_W=380).

Sticky: stageStyle.position = 'sticky', top = STICKY_TOP (12px from lib.js).
Toolbar: Desktop/Mobile segmented toggle + Fit/Actual size toggle + photo status pill.

Scale: fitFrame() called on resize, viewMode change, after doPut.
  naturalH = iframe.contentDocument.documentElement.scrollHeight.
  avail = window.innerHeight - STICKY_TOP - 14 - barH - 12 - 14.
  k = min(1, avail / mbH). Applied via mailboxRef.style.transform = scale(k).
  scalerRef height is set to Math.ceil(mbH * k).
  If viewMode='actual': no transform, scaler height is unset.

iframe: title "Email preview", sandbox="allow-same-origin", NO pointer-events override.
  Gets wheel/touch events and can steal scroll focus.

Content rendered: renderEmail + designFromTemplate from emailEngine. Debounced 120ms.
  Same engine as sent email.

Scaling limitations:
  Window resize event only — no ResizeObserver.
  Single device at a time.
  "Actual size" toggle shows iframe at native size with page scroll.

saveError.field: not consumed by PreviewStage (only the parent page routes errors).
