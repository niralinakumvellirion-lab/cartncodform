NOTE — structural difference from Today.jsx's own icon components,
not fixed (implemented literally as given)
=========================================================================
The task's given icon code hardcodes `stroke="#6366f1"` directly on
each `<svg>` and defines each icon as a zero-argument component
(`const CartIcon = () => (<svg ...>)`, no props accepted). Today.jsx's
OWN icon components (built in the immediately preceding "Today screen
redesign" task) instead use `stroke="currentColor"` and spread
`{...props}`, so a single reusable component can take a `style={{
color, marginBottom }}` prop at each call site. Both approaches render
IDENTICALLY here (a 20x20 indigo-stroke icon) since every call site in
both files applies the same #6366f1 color either way — the difference
is structural reusability, not visual output. Implemented the version
the task explicitly gave, verbatim, rather than converting to match
Today.jsx's props-based pattern (which would have been an unprompted
refactor of code the task itself supplied exactly as-is, not something
the task described as broken or asked to change). Flagging this here
for transparency should a future task want to unify the two files'
icon implementations.
