--- Insights data ---
The task assumed a single "/api/profiles/:shop/insights" endpoint.
No such route exists in backend/routes/profiles.js. Insights (and
therefore Dashboard) actually calls TWO different endpoints:

  GET /api/events/:shop/product-analytics
  (backend/routes/events.js; documented from a prior full read)
  {
    stats: {
      productViewsThisWeek,
      allowedNotifications,   // opt-in rate
      addToCartRate,
      sessionCount,
    },
    products: [
      { productId, productTitle, productPrice, views, uniqueViewers,
        addToCarts, cartRate, avgDwell },
      ...
    ]  // sorted by views desc, limited to 20
  }

  GET /api/profiles/:shop/weekly-narrative
  (backend/routes/profiles.js lines 403-434, requireAuth + requireStoreOwner)
  {
    narrative,       // string
    insights,        // array of strings -- DashboardScreen only ever
                      // renders insights[0]
    stats,           // object from computeWeeklyStats(shop) -- NOT
                      // consumed anywhere in DashboardScreen.jsx
  }
  Cached in-process (Map keyed by shop) for 1 hour; a settings PATCH
  invalidates the cache for that shop.
